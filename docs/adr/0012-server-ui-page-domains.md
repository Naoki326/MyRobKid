# 服务端浏览器页面按组件域五分，配两层折叠与页脚逃生口

配置页与摄像头页的信息架构从「八个按 YAML 相邻性凑成的分组」改为**五个页面域**（对话与角色 / 引擎 / 插件与工具 / 设备 / 系统），一域一页一 URL；域内散字段与引擎/插件卡片内部统一「常用 / 更多设置」两层折叠；原始配置只读 JSON 保留为**页脚逃生口**而非第六域。完整方案（分类规则、527 字段旧→新映射、URL 命名规则、验收自检、迁移顺序）见 `docs/design/server-ui-ia.md`。

## Context（取舍）

- 现状 527 个配置字段只有 98 个有渲染路径，81% 无归宿只能翻只读 JSON；「服务器」组按 YAML 相邻性把分属四个域的字段（`tts_timeout` / `tool_call_timeout` / `enable_websocket_ping` / `tts_audio_send_delay`）凑作一组，只因模板里紧挨着 `server:` 段落。
- 一级轴在三先例间取舍：上游智控台按 YAML 命名空间前缀（源码字面 `paramCode.startsWith('server.')`，把 `Intent.*.functions` 这张插件启用清单误判成「通用」）、OpenWrt LuCI 按管理职责域、Frigate 按作用域 × 宿主。选定**属主轴**——「把这个字段写死成常量，谁会受损」——加多属主延伸（`log.data_dir` 这类跨用途路径 → 系统域，替代路径特判）：它在四个纠缠字段（`xiaozhi.audio_params.*`、`voiceprint.speakers`、`plugins.*`、`Intent.functions`）上全部给出可解释落点，且属主可用真实代码消费点验证，不靠发明。
- 分层轴押在「是否被引用」而非「用户懂不懂」：被引用的名字（`selected_module.*`、`functions`、provisioning 载荷）改错会**静默失效**，纯参数改错能试出来——因此归属可盲测、可机械复算。
- Home Assistant 2026 年把页面级 Advanced Mode **整个废除**（`7bea54851` 等三个 commit，`advancedOnly` 现 0 命中）——「为高级内容单独设域」的先例刚被推翻。本决策的回应：不设「高级」域（属主轴套完后它名下只剩 4 个纯日志字段），「更多设置」是域内折叠容器不是域。
- 裁决过程：wayfinder 地图 [#13](https://github.com/Naoki326/MyRobKid/issues/13) 六票收敛（#14 盘点 / #15 命名台账 / #16 落位 / #17 引擎库 / #19 拓扑 / #20 危险分级）。

## Consequences

- 一级导航 = 5 域 + 逃生口 = 6 ≤ 7；深度 ≤ 3（`<details>` 折叠态 DOM 字段数 = 0，#17 原型实测）。527 字段零丢失、无重复，归属由 R1（多属主版）+ R2（两问版）+ 接入字段名字集机械复算，对账见方案 §10。
- 域页 slug（`dialogue` / `engine` / `tools` / `devices` / `system` / `raw`）一经上线即用户契约——这是「翻一次就回不去」的部分，也是单独记本 ADR 的主因；方案文档本身承载细节，ADR 只记取舍。
- 危险分级（常规/警示/危险）与折叠归属**正交**：危险是按钮的视觉属性，不是页面位置属性。
- 分类的前提是「操作者可信」（局域网免认证是刻意选择，方案不按来源收紧呈现；见方案 §0）——若未来重审威胁模型，密钥与危险操作的呈现需随之重审，分类轴本身不受影响。
- 实现从数据驱动地基开始（服务端显式判定已配置态、渲染依据配置树、元信息与键解耦），两个已知显示 bug 的修复搭首班车；实现属后续 effort，不在原地图范围内。
